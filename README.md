# إعداد الإشعارات (المتصفح + تيليجرام) — خطوة بخطوة

التطبيق نفسه بيشتغل من غير أي حاجة من دي. الإشعارات اللي بتوصل **والتطبيق مقفول** محتاجة Worker مجاني على Cloudflare.
الكود كله في `worker.js` (بيعمل: إشعارات المتصفح + بوت تيليجرام + تذكيرات مجدولة الصبح والمسا).

## 1) بوت تيليجرام
1. في تيليجرام افتحي **@BotFather** ← `/newbot` ← اختاري اسم ويوزر (لازم ينتهي بـ bot).
2. هيدّيكي **Token** شكله `123456:ABC...` — احتفظي بيه.

## لو عندك Worker شغال بالفعل (انتي كده)
- **متمسحيش حاجة:** نفس الـ KV (الاسم `KV`) ونفس مفتاح الإشعارات واشتراكات الأجهزة القديمة هيكملوا شغالين، والكود الجديد بيقرا مفتاحك القديم.
- افتحي الـ Worker ← **Edit code** ← امسحي القديم والصقي `worker.js` الجديد ← **Deploy**.
- **غيّري الـ Cron:** احذفي القديم `0 6 * * *` وضيفي `*/15 * * * *` (لو سيبتيه القديم مش هتوصل تذكيرات الصبح والمسا).
- أضيفي متغيرات الخطوة 4 تحت (خصوصًا `FIREBASE_URL`). من غيرها بيبعت التذكير العام القديم بس.
- الخطوة 1 (البوت) والخطوة 3 (الـ webhook) للتيليجرام بس، لو هتستخدميه.

## 2) الـ Worker على Cloudflare (لو لسه ما عملتيهوش)
1. ادخلي `dash.cloudflare.com` ← **Workers & Pages** ← **Create** ← **Create Worker** ← اسمه `kitchen-push` ← **Deploy**.
2. اضغطي **Edit code**، امسحي اللي فيه والصقي محتوى `worker.js`، ثم **Deploy**.
3. **KV:** من القائمة **Storage & Databases ← KV ← Create** (اسمه أي حاجة). ارجعي للـ Worker ← **Settings ← Bindings ← Add ← KV namespace**، اسم المتغير بالظبط: `KV`، واختاري الـ namespace.
4. **Settings ← Variables and Secrets** وضيفي:
   - `FIREBASE_URL` (Text) = رابط قاعدة البيانات، مثال `https://to-do-list-816f3-default-rtdb.firebaseio.com`
   - `TELEGRAM_BOT_TOKEN` (**Secret**) = التوكن من BotFather
   - `TG_SECRET` (**Secret**) = أي كلمة طويلة عشوائية (حروف وأرقام)
   - اختياري: `TZ` = `Africa/Cairo` (ده الافتراضي)، `REMIND_HOURS` = `9,18` (ساعات التذكير)
5. **Settings ← Triggers ← Cron Triggers ← Add** وحطي: `*/15 * * * *`
6. انسخي رابط الـ Worker، شكله `https://kitchen-push.اسمك.workers.dev`.

## 3) ربط البوت بالـ Worker (مرة واحدة)
افتحي الرابط ده في المتصفح بعد ما تبدّلي القيم:

`https://api.telegram.org/bot<TOKEN>/setWebhook?url=<رابط الـ Worker>/telegram&secret_token=<TG_SECRET>`

لازم يرجّع `"ok":true`.

## 4) في التطبيق
1. ارفعي ملفات التطبيق الجديدة على GitHub (استبدلي `script.js` و`style.css` و`sw.js`).
2. افتحي التطبيق ← **الأعضاء ← 🔔 الإشعارات** ← الصقي رابط الـ Worker ← **حفظ للكل** (الأدمن بس، ومرة واحدة وبيوصل لكل الأجهزة).
3. كل واحدة من موبايلها: **تفعيل** (للمتصفح) و/أو **ربط** (تيليجرام: بيفتحلك البوت، اضغطي Start).
4. اضغطي **جرّبي إشعار** للتأكد.

> آيفون: إشعارات المتصفح بتشتغل بس لو ثبّتي التطبيق على الشاشة الرئيسية (iOS 16.4+). تيليجرام شغال على أي جهاز.

## بيوصلك إيه
- تذكير الساعة ٩ صباحًا و٦ مساءً (بتوقيت `TZ`) بمهامك: الطبخ، الترتيب، تنظيف الجمعة، والمهام العادية.
- إشعار لما حد يديكي مهمة جديدة، ولما حد يخلّص مهمة.
- المشرفة بيجيلها ملخص آخر اليوم بدل المهام.
- في تيليجرام: `/today` بيرجّعلك مهام النهارده، و`/stop` بيفك الربط.

## لو حاجة مشتغلتش
- افتحي `<رابط الـ Worker>/cron?secret=<TG_SECRET>` لتشغيل التذكيرات يدويًا (بيرجّع عدد اللي اتبعت).
- تأكدي إن `FIREBASE_URL` صح وإن قواعد Firebase بتسمح بقراءة `rooms/$room`.
- مش بتوصل والتطبيق مقفول؟ اتأكدي إن الـ Cron Trigger اتضاف.
